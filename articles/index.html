  • Эластичные отводы

    Эластичные отводы изготавливаются для горнодобывающей и горноперерабатывающей промышленности для перемещения абразивных материалов, на обогатительных фабриках в трубопроводных линиях по перемещению породы для дальнейшей переработки.
